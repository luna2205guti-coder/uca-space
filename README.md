# UCA Space

MVP de UCA Space: sitio web responsive del campus, hecho con HTML5, CSS3 (Flexbox y Grid) y JavaScript.

## Tecnologías
- HTML5 semántico
- CSS3 (Flexbox y Grid)
- JavaScript

## Estructura
- `index.html`: pantalla de bienvenida
- `css/`: variables del Design System y estilos
- `js/`: interactividad
- `img/`: logo y fotografías del campus
